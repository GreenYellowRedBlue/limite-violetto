## Agent skills

### Issue tracker

GitHub Issues live in `GreenYellowRedBlue/limite-violetto`; always target this fork explicitly with `gh --repo`. Implementation issues close through PRs merged into the fork. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs
